# 🚀 Personal Portfolio Website

A modern, responsive personal portfolio website built with **HTML**, **CSS**, and **JavaScript** — featuring smooth animations, glassmorphism effects, a typing hero section, and a dark-themed premium design.

<p align="center">
  <a href="https://thakursujansingh.github.io/Portfolio/">🔗 View Live Portfolio</a>
</p>

---

## ✨ Features

| Feature | Description |
|---------|-------------|
| 🎨 **Modern Dark Theme** | Sleek dark UI with gradient accents and glassmorphism cards |
| ⌨️ **Typing Animation** | Dynamic typing effect in the hero section |
| 📱 **Fully Responsive** | Optimized for desktop, tablet, and mobile devices |
| 🧭 **Smooth Navigation** | Sticky navbar with scroll-spy active link highlighting |
| 🎭 **Scroll Animations** | Reveal-on-scroll effects for all sections |
| 🍔 **Mobile Menu** | Hamburger menu with smooth slide-in animation |
| 📊 **Interactive Stats** | Animated stat cards showcasing key achievements |
| 📬 **Contact Form** | Functional contact form with validation |

---

## 📂 Sections

- **Hero** — Introduction with typing animation, social links & CTA buttons
- **About** — Quick snapshot with stats (Projects, Certifications, Hackathons, Internships)
- **Education** — Academic timeline (B.Tech CSE AI-ML, 12th, 10th)
- **Skills** — Technical arsenal organized by category (Languages, Web, Tools, Core Concepts)
- **Training & Internships** — Hands-on experience (EduSkills, Academy of Skill Development)
- **Projects** — Featured work (Smart Attendance System, Price Comparison Site, Sales Dashboard)
- **Certifications** — Credentials from Google Cloud, IBM SkillsBuild, EduSkills, AMigo India
- **Achievements** — Hackathons & competitions (SIH 2025, SMS Internal Hackathon, Coding War)
- **Contact** — Get in touch with email, phone, LinkedIn, and a message form

## 🚀 Getting Started

1. **Clone the repository**
   ```bash
   git clone https://github.com/thakursujansingh/Portfolio.git
   ```
2. **Open in browser**
   ```bash
   cd Portfolio
   start index.html
   ```
   Or simply open `index.html` in any modern web browser.
